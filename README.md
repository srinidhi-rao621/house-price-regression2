# AI Disease Prediction

## Project Description

AI Disease Prediction is a machine learning-based application that predicts possible diseases based on symptoms provided by the user.

## Features

* Enter symptoms through the application
* Predict possible diseases using machine learning
* User-friendly interface
* Provides disease prediction based on the trained model

## Technologies Used

* Python
* Machine Learning
* Pandas
* NumPy
* Scikit-learn

## Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI_Disease_Prediction.git
```

2. Open the project folder:

```bash
cd AI_Disease_Prediction
```

3. Install the required Python packages:

```bash
pip install -r requirements.txt
```

## How to Run

Run the main Python file:

```bash
python app.py
```

Then open the application in your browser if the project uses a web interface.
